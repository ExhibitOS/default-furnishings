# ExhibitOS Default Furnishings

Version 1.5.0 contains eleven CC0 furnishing models and their exact rights notices. `manifest.json` records stable catalog identifiers, versions, paths, lengths, SHA-256 hashes and source provenance. The exit pictogram sign includes its original source and product-prepared display model. The closed exit door and exit pictogram sign are independent assets; exit links and behavior belong to an explicitly configured placed door, not the sign. The black aluminum frame includes the retained source and the product-prepared renderable; its supported attachment and fit limits are described in its provenance file.

These assets preserve the existing ExhibitOS catalog bytes. Manager installation integration and offline availability require a separately verified product build. The release does not itself install or register assets.

Each asset is licensed CC0 1.0 within the creator’s rights; see its accompanying notice. Product source code is not included.

Version 1.6.0 preserves all eleven 1.5.0 entries and adds the existing ExhibitOS-created pale-mineral and warm-oak portal originals with their exact CC0 notices. These are unchanged distribution sources; geometry eligibility, reusable fit, owner registration, clean installation and walking require product consumer qualification.

Version 1.7.0 preserves all 1.6.0 entries and adds the original compact caption stand. Its registration, installed availability, placement, physical support and caption readability require product consumer qualification.

Version 1.8.0 preserves all 1.7.0 entries and adds the museum wallwasher with its original source, product-prepared model, rights notices and producer evidence. Fixture selection, optical fit, installation and Viewer behavior require separate product qualification.

Version 1.9.0 preserves all 1.8.0 entries and adds the rear-relief museum wallwasher as a distinct source and prepared model with its rights notices and producer evidence. Catalogue admission, fixture selection, fit, installation and Viewer behavior require separate product qualification.

Version 1.10.0 preserves all 1.9.0 entries and adds the original Sculpture Bench Refined model. Clean-install discovery, placement, seating, walking and Viewer behavior require separate product qualification.

Version 1.11.0 preserves all seventeen 1.10.0 entries and adds the unchanged original recessed downlight and its exact CC0 notice. The authored -Y fixture axis and aperture reference require product host alignment; this distribution alone does not establish mounting, ceiling recess geometry, optics, placement or Viewer qualification.

Version 1.12.0 preserves all eighteen 1.11.0 entries and adds the unchanged original Thin Brass Frame, a new CC0 distribution notice, its retained historical source notice, and authored installed-frame metadata. Its source-bound straight-miter fit uses the existing public profile. The immutable 256-pixel card is the product-rendered PNG bound to that exact model, installed descriptor, rights and render recipe/job. Its safe distribution metadata contains no private tenant session, actor or filesystem information. Tenant registrations and their mutable thumbnail selections remain separate. Installation, discovery, actual card display, Save/reopen and Viewer use require separately qualified product consumers.
