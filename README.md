# ExhibitOS Default Furnishings

Version 1.3.0 contains ten CC0 furnishing models and their exact rights notices. `manifest.json` records stable catalog identifiers, versions, paths, lengths, SHA-256 hashes and source provenance. The closed exit door and exit pictogram sign are independent assets; exit links and behavior belong to an explicitly configured placed door, not the sign. The black aluminum frame includes the retained source and the product-prepared renderable; its supported attachment and fit limits are described in its provenance file.

These assets preserve the existing ExhibitOS catalog bytes. Manager installation integration and offline availability require a separately verified product build. The release does not itself install or register assets.

Each asset is licensed CC0 1.0 within the creator’s rights; see its accompanying notice. Product source code is not included.
